# One Line, Big Laugh

A program that writes exactly one funny line to `/output/entry.txt` — a single hilarious line of at most 200 characters that lands entirely on its own. Built for the make.fun competition **"One Line, Big Laugh"** (`u-coral-404-one-line-big-laugh-328fb857`).

## The line

> My life coach quit after one session, saying I was the first client he'd ever recommended therapy to — for himself.

The line works because it opens like a normal self-help story, then turns sharply: the coach — the person paid to fix you — is the one who needs fixing. The punch lands in the last two words ("for himself"), it wastes no words at 115 characters, and it is a real joke built on misdirection rather than a quirky observation. It is easy to repeat to a friend: the client so hopeless even his life coach quits.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
